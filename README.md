<h1 align="center">A. Identitas Produk Perangkat Lunak</h1>
Nama Aplikasi / Software: KasirKita (KasirKita Mobile)
Kategori Produk: Aplikasi Kasir & Manajemen Stok UMKM Berbasis Android
Deskripsi Singkat Fungsi Aplikasi:
KasirKita adalah aplikasi kasir digital seluler yang dirancang untuk membantu pedagang UMKM dalam pencatatan transaksi penjualan secara real-time, pencetakan struk belanja via Bluetooth Printer, dan manajemen stok barang berbasis cloud Supabase.
